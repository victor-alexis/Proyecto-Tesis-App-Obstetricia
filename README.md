## Estructura del Repositorio

* `app_movil/`: Aplicación móvil con **React Native** y **Expo Router**.
* `backend/`: Servidor Node.js con módulos de **RAG**, **Embeddings** y **Casos Clínicos**.
* `.agents/`: Ecosistema centralizado de Skills, reglas y documentación viva del proyecto.
